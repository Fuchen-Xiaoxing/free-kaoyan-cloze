## 一、认知总纲、执行铁律与七板块母版

### 1. 认知总纲：完形解题赋能与语言底层

> **【总纲金句】**
> “**世间人，法无定法，然后知非法法也。天下事，了犹未了，何妨以不了了之。**”  
> “**世界是物质的（名词），物质是运动的（动词）。** 完形填空测试的本质，归根到底考查的就是**动词与名词的搭配网络（小宇宙）**以及**句子与句子之间的逻辑胶水（中宇宙）**，其他修饰性语法皆为这两大核心的延伸。”  
> 完形填空中的句子往往长达 25~45 词，且包含 1~2 处挖空。学生之所以觉得难，不是单词不认识，而是被**复杂的从句嵌套、长距离主谓隔离以及非谓语修饰**蒙蔽了双眼，导致找不清动作的施受者、看不出句际逻辑的转折。面对任何复杂设空句，只需建立三大核心能力：**句内逻辑切分能力（模块化断句）**、**重点信息提取能力（去 70% 次要信息抓主干）**与**核心态度洞察能力（褒贬与极性翻转）**。读长难句不是做逐字翻译苦工，而是精准为完形解题破案赋能！

### 2. 长难句拆解三大执行铁律

> [!IMPORTANT]
> **长难句拆解三大执行铁律**：
> 1. **默认选句原则**：讲解的长难句**默认且必须是当前空格所在的核心解题判定句（题眼句）**；原句中的空格处**必须补全正确答案并加粗显示**（如 `... can **reduce** the risk ...`），展示语法完整的基准句；当用户提出"讲解长难句/讲语法"时，默认直接拆解该句，严禁向用户反问"你想讲哪一句"。
> 2. **极简注释与零音标原则**：遵循 `references/style-guide.md` 规范，直接给出 `单词 + 词性 + 考研核心语境释义 + 态度色彩`，坚守**零音标原则**，杜绝视觉冗余。
> 3. **积木独立换行与纯编号原则**：【板块二】中，**每个积木块必须独立占一行展示**，严禁将整句积木堆叠在同一行内；积木标签**仅保留纯序号 `[1]`、`[2]`...，严禁添加冗杂中文标签**。

### 3. 标准化长难句 七板块完整输出母版（首屏速查）

```markdown
#### 【板块一：原句呈现与核心词汇】
> **原句（空格处补全加粗）**：*Sentence text with correct answer filled in and **bolded**...*
> **核心词汇精讲**：
> - `word 1` n./v. 考研核心释义（逻辑态度色彩 / 考点搭配）
> - `word 2` adj./adv. 考研核心释义（逻辑态度色彩）

#### 【板块二：模块化断句与结构积木】
- **断句切分（逐块换行，保留纯编号）**：
  - `[1]` In recent years,...
  - `[2]` scientists have discovered...
  - `[3]` that our brain structure changes...
  - `[4]` which can **influence** daily decisions.
- **积木属性剖析**：
  - **[1]**：时间状语介词短语，交代背景；
  - **[2]**：主句核心主谓（落单谓语动词 have discovered）；
  - **[3]**：that 引导的宾语从句，充当 discovered 的宾语；
  - **[4]**：which 引导的非限制性定语从句，设空处 **influence** 充当从句谓语。

#### 【板块三：语法骨架与核心主干】
- **核心骨架**：**Scientists have discovered that...** (S + V + O)
- **主干提取说明**：剥离次要时间状语与后置从句修饰，提炼核心主谓宾。

#### 【板块四：核心语法难点与机制剖析】
- **核心语法难点**：主谓隔离 / 从句嵌套 / 非谓语修饰 / 特殊句式
- **膨胀与干扰机制剖析**：剖析句子核心膨胀机制与认知干扰点（如后置定语从句嵌套、长介词短语隔离主谓、并列结构“看后找同”等）。

#### 【板块五：积木组装与全句宏观分析】
- **增量式积木组装**：
  - **Step 1（核心主干）**：`scientists have discovered...`（使用积木：`[2]`）
  - **Step 2（嵌入宾从）**：`scientists have discovered that our brain structure changes...`（使用积木：`[3]`，新增片段："that our brain structure changes"，充当 discovered 的宾语从句）
  - **Step 3（添加定从）**：`scientists have discovered that our brain structure changes which can influence daily decisions.`（使用积木：`[4]`，新增片段："which can influence daily decisions"，充当后置定语修饰先行词）
  - **Step 4（还原全句）**：`In recent years, scientists have discovered that our brain structure changes which can influence daily decisions.`（使用积木：`[1]`，新增片段："In recent years,"，充当全句时间状语）
- **全句宏观透视分析**：
  - **主句结论**：科学家发现了大脑结构的改变；
  - **关键信息**：大脑改变会影响日常决策；
  - **次要修饰**：近年来（时间背景）；
  - **逻辑方向**：顺承事实陈述；
  - **阅读压缩句**：*Scientists found brain changes affect decisions.*

#### 【板块六：双层翻译示范】
- **第一层：模块顺译（机械直译）**：近年来，/ 科学家们已经发现 / 我们的大脑结构会发生改变，/ 这种改变能够影响日常决策。
- **第二层：地道优化（中文润色）**：近年来，科学家们发现人类的大脑结构正在发生改变，而这一改变能够对我们的日常决策产生重要影响。

#### 【板块七：完形赋能与命题透视】
- **设空机理与题眼映射**：设空位于积木 `[4]` 的从句谓语，属于典型小宇宙修饰对应题，由先行词 `changes` 与宾语 `daily decisions` 构成动宾与主谓逻辑闭环。
- **线索闭环与选项锁定**：事物名词（changes）作主语，只能选择表达客观影响或引发的动词，结合语义范畴放缩锁定 `influence`。
- **干扰陷阱透视**：干扰项常设置需要人作主语的动词（如 `intend, doubt`）或及物性缺失的不及物动词（如 `rely` 未带 on），考生若被长定语从句结构搞晕容易误选。
```

## 二、标准化长难句 七板块深度解析与方法论指导

### 【板块一：原句呈现与核心词汇】

#### 1. 规范输出格式
```markdown
#### 【板块一：原句呈现与核心词汇】
> **原句（空格处补全加粗）**：*原句英文斜体，设空处补全正确答案并加粗...*
> **核心词汇精讲**：
> - `单词/短语` 词性. 考研核心语境释义（态度色彩 / 搭配考点）
```

#### 2. 方法论指导与底层原理
1. **设空处补全加粗**：展示给学生的是语法与语义完整的基准句，设空词用 `**word**` 加粗，使其一目了然看清正确词在句中的角色。
2. **抓核心实词与逻辑标志词**：精讲优先锁定决定该句骨架的谓语动词、核心名词以及句际逻辑标志词（转折/因果/让步）。
3. **态度色彩与语境内核**：明确标出单词感情色彩（正向 `+`、负向 `-` 或中性），讲透语义范畴放缩（如 `address` 的“应对/解决”内核）。
4. **零音标铁律**：坚决贯彻零音标原则，杜绝英美音标堆砌。

---

### 【板块二：模块化断句与结构积木】

#### 1. 规范输出格式
```markdown
#### 【板块二：模块化断句与结构积木】
- **断句切分（逐块换行，保留纯编号）**：
  - `[1]` 语言片段 1...
  - `[2]` 语言片段 2...
  - `[3]` 语言片段 3...
- **积木属性剖析**：
  - **[1]**：语法功能与修饰角色；
  - **[2]**：语法功能与修饰角色；
  - **[3]**：语法功能与修饰角色。
```

#### 2. 方法论指导与底层原理
1. **模块化积木模型（Sentence Lego Model）**：
   任何复杂长难句均由 3~5 个相对独立的语言积木拼接而成：
   $$\mathbf{[时间/条件状语]} + \mathbf{[主句核心主谓宾]} + \mathbf{[定语修饰/从句]} + \mathbf{[伴随/结果状语]}$$
2. **模块化切分三大铁律**：
   - **遇界必断**：在标点符号（逗号、分号、破折号）、从句引导词（that, which, who, when 等）、逻辑连词（FANBOYS, because, although 等）以及落单谓语动词处划线切开；
   - **闭环分析**：切断后的每个模块是一个独立的语法闭环，所有微观修饰分析只在该模块内部进行；
   - **分层折叠**：区分核心主干积木（必读保留）与次要修饰积木（跳读折叠）。
3. **输出硬约束**：积木必须**逐块换行独立展示**；标签必须使用纯序号 `[1]`、`[2]`...，严禁加入冗杂中文标签。

---

### 【板块三：语法骨架与核心主干】

#### 1. 规范输出格式
```markdown
#### 【板块三：语法骨架与核心主干】
- **核心骨架**：**Subject + Verb + Object / Predicative...**
- **主干提取逻辑**：说明剥离了哪些次要修饰/插入语，保留了何种核心骨架。
```

#### 2. 方法论指导与底层原理
1. **去 70% 次要信息抓主干**：长难句 70% 文字属于铺垫修饰。考场做题必须启动“剔骨留肉”机制，快速锁定主谓宾/主系表。
2. **极速过滤清单（果断折叠跳读）**：
   - 插入语（双逗号/双破折号间的内容、`for example` 细节）；
   - 让步状语从句（`Although / Even though...`，重心永远在主句）；
   - 冗长的前置/后置介词短语修饰；
   - 对比中的否定方（`rather than B, instead of B`，视线锁定肯定方）。

---

### 【板块四：核心语法难点与机制剖析】

#### 1. 规范输出格式
```markdown
#### 【板块四：核心语法难点与机制剖析】
- **核心语法难点**：主谓隔离 / 从句嵌套 / 非谓语修饰 / 特殊句式
- **膨胀与干扰机制剖析**：深入说明句子如何从简单主干通过三大膨胀机制（从句嵌套、介词短语、非谓语修饰）与逻辑连接词膨胀变长，剖析认知干扰点。
```

#### 2. 方法论指导与三大破解法则
1. **主谓长距离物理隔离突破**：寻找没有从属连词引导的“落单谓语动词”，将其与句首主语重新咬合。
2. **并列连词“看后找同”法则（Align）**：遇到 `and / or / but`，死盯后面的词性与形态，向前寻找同层级成分，破解并列结构造成的混淆。
3. **从句嵌套分层剥离**：理清主句谓语与从句谓语的所属层级，防止把从句谓语误当成全句主干动作。

### 【板块五：积木组装与全句宏观分析】

#### 1. 规范输出格式
```markdown
#### 【板块五：积木组装与全句宏观分析】
- **增量式积木组装（从骨架到全句逐步还原）**：
  - **Step 1（核心主干）**：`[核心主干英文真实片段]`（使用积木：`[x]`）
  - **Step 2（嵌入第一层修饰/从句）**：`[在已有基础上增加真实英文]`（使用积木：`[y]`，新增片段："..."，语法功能说明）
  - **Step 3（逐级叠加...）**：...
  - **Step N（还原完整原句）**：`[逐字还原完整英文原句]`（使用积木：`[z]`，新增片段："..."）
- **全句宏观透视分析**：
  - **主句结论**：...
  - **关键信息**：...
  - **次要修饰**：...
  - **逻辑方向**：...（顺承 / 转折 / 让步 / 因果 / 对比）
  - **阅读极速压缩句**：*一句话提炼考场阅读保留版本...*
```

#### 2. 八大硬性操作规则
1. **真实语言片段原则**：每步写出真实英文原句片段，标明使用积木；
2. **严禁抽象代称原则**：禁止只用 `[1] + [2]` 或“主句+从句”等抽象代称；
3. **增量推进原则**：每步必须比上一步增加真实英文内容；
4. **累积保留原则**：每步保留截至当前已组装的完整句子；
5. **原句复制原则**：新增片段逐字复制原句内容；
6. **关系明确原则**：说明修饰谁、充当何种成分；
7. **完整还原原则**：最后一步逐字还原完整原句，不得用省略号；
8. **宏观分析五要素**：包含主句结论、关键信息、次要修饰、逻辑方向、阅读极速压缩句。

## 三、实战流水线总结：“四步搞定一句话”

```
│                    通用实战流程：“四步搞定一句话”                             │
├──────────┬──────────────────────┬─────────────────────────────┬─────────────┤
│  步骤    │ 动作名称             │ 核心操作与执行铁律          │ 对应板块    │
├──────────┼──────────────────────┼─────────────────────────────┼─────────────┤
│  Step 1  │ 拆分断句 (Segment)   │ 遇标点、引导词、连词立即切  │ 板块二      │
│          │                      │ 开，化长为短（3~5 块积木）  │             │
├──────────┼──────────────────────┼─────────────────────────────┼─────────────┤
│  Step 2  │ 抓主干提重点 (Strip) │ 剔除插入语、介词短语、让步  │ 板块三      │
│          │                      │ 从句，去 70% 次要信息抓主干 │             │
├──────────┼──────────────────────┼─────────────────────────────┼─────────────┤
│  Step 3  │ 判并列修饰 (Align)   │ 死盯 and/or 紧贴词性，向前  │ 板块四、五  │
│          │                      │ 找同属性成分，理顺组装层级  │             │
├──────────┼──────────────────────┼─────────────────────────────┼─────────────┤
│  Step 4  │ 抓态度透解题 (Tone)  │ 捕捉动/形感情色彩，直击题眼 │ 板块六、七  │
│          │                      │ 与搭配线索，秒杀正确选项    │             │
└──────────┴──────────────────────┴─────────────────────────────┴─────────────┘
```

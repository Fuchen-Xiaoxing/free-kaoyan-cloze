> **加载时机**：仅当进入**阶段 3**（错题归档）调用 `record_error.py` 构造入库条目时按需读取本文件。日常讲题与错题复盘（阶段 0-2）严禁加载，保持会话精简与零延迟。

## 一、12 类错误类型与能力短板（封闭枚举）

### 12 类错误类型（封闭枚举）
1. **宇宙定级错误** —— 视窗受限，死抠本句，忽略相邻句（中宇宙）或段首/全文主旨（大宇宙）核心线索
2. **直觉先入为主** —— 未执行遮选预填，直接看选项代入，被中文表面通顺带入思维陷阱
3. **逻辑关系误判** —— 转折/因果/让步/并列/条件等句际逻辑判定颠倒或混淆
4. **态度极性倒错** —— 忽略转折标志词或隐性否定，选项正负感情色彩与语境基调背离
5. **动宾/主谓不配** —— 动作施受不当、人/物主客观错位、抽象与具体范畴不匹配
6. **修饰限定背离** —— 忽略定语/状语/同位语的核心限定，与后置修饰或语境冲突
7. **及物/不及物违背** —— 忽略动词及物性约束或介词搭配句法边界
8. **词义/僻义误解** —— 核心大纲词不认识、形近词混淆或语义范畴放缩失败
9. **虚词同义通斥误选** —— 误选两个或多个同义互斥的虚词（如 although 与 while 同义互斥）
10. **细节背离主旨** —— 局部代入看似通顺，但违背不设空首句确立的全文中心基调
11. **时序与时态悖论** —— 违背动作先决时序或未发生/既成事实的时态约束
12. **选项误读** —— 选项看反意思、漏看否定词、审题粗心失误

### 能力短板三件套（封闭集合）
- **词汇**：实词语义范畴放缩失败、虚词逻辑功能不清、熟词僻义或态度色彩失误
- **语法**：长难句断句拆解失败、及物性与介词搭配失误、修饰成分归属不清
- **主旨**：全文宏观基调把握失误、重要信息捕捉失败、细节背离主旨

## 二、存储位置与写入原则

- **存储文件与路径**：`错题本.md` 默认安全持久化存储于 **Android 手机公共文档目录**（优先 Open Minis 挂载外部文档 `/var/minis/mounts/Documents/考研英语/错题本.md` 或系统公共文档 `/storage/emulated/0/Documents/考研英语/错题本.md`，支持通过 Obsidian、WPS 或系统文件管理器直接复习；未挂载外部目录时安全保存在沙箱工作区 `/var/minis/workspace/错题本.md`），彻底与 Skill 目录解耦；更新、重新克隆或重装 Skill 绝不丢失历史数据。支持环境变量 `KAOYAN_ERROR_NOTEBOOK` 自定义指定（带路径自愈纠偏）。
- **写入规则**：**只追加、不覆盖、不修改历史条目**。一律通过 `scripts/record_error.py` 写入（自动清理占位符与安全迁移旧数据），禁止手工拼写。
- **定位与边界**：错题本仅用于篇末归档沉淀与自主复习，日常讲解过程中不主动查阅、检索或关联历史错题。

## 三、条目 Schema (YAML frontmatter + 正文)

```markdown
---
id: 2015-Cloze-Q05
刷次: 一刷
题型: 动词题
error_type: 动宾/主谓不配
secondary_error_types: [直觉先入为主]
user_answer: C
correct_answer: A
能力短板: 词汇
解题关键词: 题眼搭配词
原文定位: 第 2 段第 2 句 (L15)
错误还原: 我怎么错的、选了哪个选项、为什么这么选
方法论归因: 违背/忽略了哪条方法论原则
教训金句: 一句话教训
---

### 2015-Cloze-Q05

正文：详细的错误分析与复盘，用完形方法论术语展开。
```

## 四、字段说明与约束

| 字段名 | 必填 | 取值约束与说明 |
| :--- | :---: | :--- |
| `id` | 是 | 统一标准规范 ID：`YYYY-[E1-|E2-]Cloze-Q[01-20]`（如 `2015-Cloze-Q05`、`2021-E1-Cloze-Q12`；重复时脚本自动追加 `-2`, `-3`，自动纠偏变体格式） |
| `刷次` / `round` | 否 | 默认 `一刷`。若用户在对话中说明是二刷/三刷，则记录为 `二刷`/`三刷` |
| `题型` / `question_type` | 是 | 动词题 / 逻辑关系题 / 名词题 / 形容词副词题 / 代词题 / 介词与虚词搭配题 |
| `error_type` | 是 | **必须严格属于上述 12 类错误类型封闭枚举之一**（主错误类型） |
| `secondary_error_types` | 否 | 副错误类型列表（数组，值必须属于 12 类枚举之一，记录复合错误） |
| `user_answer` | 否 | 用户选择的选项（如 `C`） |
| `correct_answer` | 否 | 正确选项（如 `A`） |
| `能力短板` / `ability_shortboard` | 是 | **必须严格属于 {词汇, 语法, 主旨} 封闭集合之一** |
| `解题关键词` / `keyword` | 是 | 题眼搭配词、句际逻辑标志词或核心解题切入点 |
| `原文定位` / `location` | 是 | 设空所在段落或行号 |
| `错误还原` / `restore` | 是 | 以错题复盘中用户自述思路 + 诊断出的思维误区为准，真实记录，禁止凭空编造 |
| `方法论归因` / `attribution` | 是 | 违背或忽略的方法论原则（如宇宙定级、遮选预填、三大对应、红花词双保险等） |
| `教训金句` / `lesson` | 是 | 一句话前瞻教训与应对解法 |
| `正文` / `analysis` | 是 | 详细的错误分析与复盘 |
